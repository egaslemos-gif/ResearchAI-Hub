# PR-010 — Checklist Final de Validação

Actua como revisor científico experiente.

Acabei de concluir uma revisão da literatura sobre o tema: **{{research_topic}}**

Revê o meu trabalho com base no seguinte checklist de qualidade. Para cada item, avalia se o critério está cumprido e, caso não esteja, sugere como corrigi-lo.

## Checklist de Validação

### Definição do Problema
- [ ] O tema está claramente definido e delimitado
- [ ] A pergunta de investigação é específica, clara e respondível
- [ ] Os objectivos são mensuráveis e coerentes com a pergunta
- [ ] As palavras-chave estão definidas em PT e EN

### Pesquisa da Literatura
- [ ] Foi utilizada pelo menos uma ferramenta de descoberta científica
- [ ] Foram testadas múltiplas formulações de pesquisa
- [ ] Os artigos são de fontes peer-reviewed
- [ ] Foram definidos critérios de inclusão e exclusão
- [ ] Foram seleccionados entre 5 e 8 artigos relevantes

### Análise e Comparação
- [ ] Cada artigo possui uma ficha de leitura completa
- [ ] As fichas contêm objectivo, metodologia, resultados e limitações
- [ ] Foi produzida uma tabela comparativa
- [ ] Convergências e divergências estão identificadas

### Síntese e Produção
- [ ] Foram identificadas pelo menos 3 lacunas
- [ ] A síntese está organizada por temas
- [ ] A revisão possui introdução, desenvolvimento e conclusão
- [ ] Todas as afirmações são suportadas por referências
- [ ] O texto está em linguagem académica clara

### Rigor e Ética
- [ ] Todas as citações foram verificadas pessoalmente
- [ ] Não existem passagens copiadas sem citação
- [ ] O texto reflecte a análise do investigador
- [ ] O investigador é capaz de defender cada afirmação

Para cada item NÃO cumprido, indica:
1. O que está em falta
2. Em que etapa do protocolo deverá ser corrigido
3. Sugestão concreta de correcção
