# PR-003 — Pesquisa no Consensus

---

Este prompt NÃO é para a IA. É uma instrução directa para o investigador utilizar o Consensus.

---

## Instruções para pesquisa no Consensus

1. Aceda a [consensus.app](https://consensus.app).

2. Traduza a sua pergunta de investigação para inglês. Use a seguinte formulação:

   **Pergunta original (PT):** {{research_question_pt}}

   **Sugestão de tradução (EN):** {{research_question_en}}

3. Cole a pergunta traduzida na barra de pesquisa do Consensus.

4. Analise os resultados:
   - Verifique o indicador de consenso (YES / POSSIBLY / NO / MIXED)
   - Leia os resumos dos primeiros 10-15 resultados
   - Identifique os artigos mais citados

5. Teste **pelo menos 2 formulações alternativas**:

   **Alternativa 1:** Utilize sinónimos das palavras-chave
   
   **Alternativa 2:** Reformule a pergunta focando num aspecto diferente

6. Para cada artigo relevante, registe:
   - Título
   - Autores
   - Ano de publicação
   - Journal
   - Resumo das conclusões principais

7. Exporte ou copie as referências dos 10-20 artigos mais relevantes.

---

**Resultado esperado:** Lista de 10-20 artigos candidatos com metadados completos.
