# Consensus — Guia de Utilização

## O que é o Consensus?

O Consensus é um motor de pesquisa científica que utiliza Inteligência Artificial para encontrar respostas directamente a partir de artigos peer-reviewed. Em vez de mostrar links como o Google, o Consensus lê os artigos e sintetiza o que a ciência diz sobre a sua pergunta.

## Quando utilizar?

Utilize o Consensus quando precisar de:

- Ter uma visão geral rápida sobre o que a ciência diz sobre um tema
- Encontrar artigos relevantes sem navegar em bases de dados complexas
- Verificar se existe consenso científico sobre uma afirmação
- Começar uma revisão da literatura com artigos de qualidade

## Como aceder?

1. Aceda a [consensus.app](https://consensus.app)
2. Crie uma conta gratuita
3. A versão gratuita permite um número limitado de pesquisas por dia

## Boas Práticas

### Formule perguntas em inglês
O Consensus funciona melhor com perguntas em inglês. Traduza a sua pergunta de investigação.

**Menos eficaz:** "impacto da inteligência artificial na educação"

**Mais eficaz:** "What is the impact of artificial intelligence on student learning outcomes in higher education?"

### Teste múltiplas formulações
A mesma pergunta pode gerar resultados diferentes conforme a formulação. Teste pelo menos 2-3 variações.

**Variação 1:** "Does AI improve academic performance in university students?"

**Variação 2:** "What are the effects of generative AI tools on learning outcomes in higher education?"

**Variação 3:** "How does ChatGPT usage affect student performance in academic settings?"

### Verifique o indicador de consenso
O Consensus mostra um indicador que resume o que os estudos dizem:

| Indicador | Significado |
|-----------|-------------|
| YES       | A maioria dos estudos concorda com a afirmação |
| POSSIBLY  | Alguns estudos apoiam, mas os resultados são mistos |
| NO        | A maioria dos estudos não apoia a afirmação |
| MIXED     | Os estudos apresentam resultados contraditórios |

**Importante:** Este indicador é algorítmico. Valide pessoalmente lendo os abstracts.

### Utilize os filtros
- Filtre por **ano** para obter artigos recentes (últimos 5 anos)
- Filtre por **tipo de estudo** quando disponível

## Limitações

- Disponível apenas em inglês
- Base de dados menor que Scopus ou Web of Science
- A versão gratuita tem limite de pesquisas diárias
- Não cobre todos os journals — complete com outras fontes
- O consenso indicado é algorítmico e pode não reflectir nuances da área

## Dentro do ResearchAI Hub

O Consensus é utilizado na **Etapa 3** do protocolo LIT-RL-01 (Pesquisar Literatura) como ferramenta principal de descoberta científica.
