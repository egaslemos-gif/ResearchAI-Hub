# SPEC-010: Terminology Contract

## 1. Visão Geral
A linguagem constrói o produto. O **ResearchAI Hub** *não* é um LMS (Learning Management System), *não* é um SaaS de produtividade genérico e *não* é um curso online. O contrato de terminologia garante que a plataforma comunica com rigor metodológico, nivelando o discurso por cima (Academic Grade).

## 2. Termos Autorizados (Obrigatórios)

| Termo Oficial | Definição / Uso Contextual |
| :--- | :--- |
| **Plataforma / Hub** | O ambiente geral onde o investigador se encontra (nunca "App" ou "Site"). |
| **Investigador** | O utilizador (nunca "Aluno", "Cliente", "User"). |
| **Competência** | O grande bloco de conhecimento a dominar (ex: Revisão da Literatura, Escrita Científica). |
| **Percursos de Investigação** | O catálogo completo de Necessidades Académicas (ResearchNeeds). |
| **Guia Prático** | A interface guiada dentro de uma Competência. |
| **Passo** | Uma unidade atómica de execução num Guia Prático (nunca "Módulo" ou "Lição"). |
| **Evidência** | O resultado cognitivo ou documental gerado no final de um Passo (nunca "Tarefa" ou "Homework"). |
| **Protocolo** | O motor metodológico (ex: RL-01) subjacente ao Guia Prático. |
| **Ferramenta** | Software ou IA utilizado para alavancar a pesquisa (ex: ChatGPT, Consensus). |
| **Prompt** | O input estruturado de engenharia para comunicar com a IA. |
| **Checklist de Qualidade** | A validação final antes de concluir uma secção ou Passo. |

## 3. Termos Proibidos (Lista Negra)
Qualquer contribuição (código, texto, prompts) que inclua estes termos será rejeitada:

- ❌ **Módulo, Lição, Curso, Aula**: O Hub não é um LMS passivo. É um ambiente de produção ("Aprender produzindo evidências").
- ❌ **Tarefa, TPC, Homework**: Linguagem infantilizadora. Substituir por "Passo" ou "Evidência".
- ❌ **App, Aplicação**: Demasiado genérico ou focado em mobile. Usar "Plataforma" ou "Hub".
- ❌ **Dashboard**: Remete para SaaS financeiro/administrativo. Usar "Início" ou "Workspace".
- ❌ **Gamification, Pontos, Níveis**: Proibido recorrer a truques de dopamina baratos. A recompensa é o conhecimento científico adquirido.
- ❌ **Mágico, Automático, "Num clique"**: O Hub defende que a IA apoia o pensamento, não o substitui. O trabalho académico exige esforço cognitivo.

## 4. Estilo de Cópia (Microcopy)
- Os botões (Call to Action) devem ser verbos fortes e precisos: "Concluir e ver checklist", "Começar o Guia Prático".
- Mensagens de erro ou *empty states* não usam piadas ou emojis jocosos. Mantêm o tom clínico mas prestativo (ex: "Ainda não existem ferramentas associadas a este protocolo.").
